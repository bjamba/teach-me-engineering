GDScript Reference Playground

Tool · quick-access GDScript patterns · for senior devs coming from other languages

GDScript can't execute in a browser — it needs the Godot runtime. But 90% of your "wait, how do I do X in GDScript?" moments are pattern-recognition. This tool is a fast-index reference of the patterns you'll use weekly in Lexicon Duel, with SWE-to-Godot analogues.

How to use: browse the left sidebar, click a pattern, read the code + explanation on the right. Click "Copy" to grab it. This is a bookmarked tab, not a tutorial — come back to it.
