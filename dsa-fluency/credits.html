Credits & sources

This course is built entirely from the ground up — no external images, audio, or video are embedded. Every visualization is rendered live in your browser from vanilla JS / SVG. The libraries below power the runtime experience.

Open-source libraries (CDN-loaded at runtime)

  • Pyodide — Python distribution compiled to WebAssembly, used to execute Python code directly in your browser.
    pyodide.org · MPL-2.0
  • TypeScript — The TypeScript compiler bundle, used to transpile TypeScript drills to JavaScript before execution.
    typescriptlang.org · Apache-2.0
  • canvas-confetti — celebration effects on milestone completion.
    github.com/catdad/canvas-confetti · ISC license

Curricular shape

The module ordering and drill selection are influenced by the public DSA-prep traditions of Cracking the Coding Interview (McDowell), Elements of Programming Interviews (Aziz/Lee/Prakash), the open NeetCode 150 problem list, and decades of community problems from LeetCode and HackerRank. No problem statements, solutions, or text from those sources are reproduced — the drills here are written fresh in the voice of this course.
