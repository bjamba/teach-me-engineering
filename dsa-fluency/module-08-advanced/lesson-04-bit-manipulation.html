Bit manipulation — when integers are sets

When the data fits in a 32- or 64-bit integer, every operation is parallelism. Set membership for n ≤ 64 is one machine word. Subset enumeration is one loop. The tricks are weird at first and unforgettable once you see them.

The metaphor: a row of light switches

Each bit of an integer is a light switch. Switching one on or off is O(1). Asking "is this switch on?" is O(1). Reading all 64 switches at once is O(1) — that's the entire integer. When you can encode your problem as "which subset of switches is currently flipped," you've unlocked a new family of algorithms.

The metaphor

An integer is a row of switches. Bitwise ops are "flip all of these at once." Hardware does it in one cycle.

Why x & (x-1) clears the lowest set bit

Subtracting 1 flips the lowest set bit AND every zero below it. ANDing with the original kills exactly the lowest set bit. Repeating this is the simplest way to count set bits — Brian Kernighan's popcount.

The XOR magic — finding the unique element

XOR has two key properties: x ^ x = 0 and x ^ 0 = x. So if you XOR all elements of an array where every value appears twice except one, all the pairs cancel and you're left with the loner.

def single_number(nums):
    r = 0
    for x in nums: r ^= x
    return r
# O(n) time, O(1) space — beats hash-set version on space
function singleNumber(nums) {
  let r = 0;
  for (const x of nums) r ^= x;
  return r;
}

  for (const x of nums) r ^= x;
  return r;
}

Subset enumeration — the bit-mask trick

To enumerate all 2ⁿ subsets of an n-element set (for n ≤ ~25), iterate i from 0 to (1 << n) - 1 and treat each i as a binary bitmask of which elements are included.

def all_subsets(elements):
    n = len(elements)
    out = []
    for mask in range(1 << n):
        subset = [elements[i] for i in range(n) if (mask >> i) & 1]
        out.append(subset)
    return out
# O(n × 2^n) — generates all 2^n subsets
function allSubsets(elements) {
  const n = elements.length;
  const out = [];
  for (let mask = 0; mask < (1 << n); mask++) {
    const subset = [];
    for (let i = 0; i < n; i++) {
      if ((mask >> i) & 1) subset.push(elements[i]);
    }
    out.push(subset);
  }
  return out;
}
// O(n × 2^n) — generates all 2^n subsets
function allSubsets<T>(elements: T[]): T[][] {
  const n = elements.length;
  const out: T[][] = [];
  for (let mask = 0; mask < (1 << n); mask++) {
    const subset: T[] = [];
    for (let i = 0; i < n; i++) {
      if ((mask >> i) & 1) subset.push(elements[i]);
    }
    out.push(subset);
  }
  return out;
}
// O(n × 2^n) — generates all 2^n subsets

Popcount — counting set bits

def popcount(x):
    c = 0
    while x:
        x &= x - 1     # Brian Kernighan's: kill lowest set bit
        c += 1
    return c
# O(set bits) — Python also has bin(x).count('1') and int.bit_count()
function popcount(x) {
  let c = 0;
  while (x) {
    x &= x - 1;     // Brian Kernighan's: kill lowest set bit
    c++;
  }
  return c;
}
// O(set bits) — also: x.toString(2).split('1').length - 1
// JS bitwise ops are 32-bit; for >32-bit values, split into halves or use BigInt.
function popcount(x: number): number {
  let c = 0;
  while (x) {
    x &= x - 1;     // Brian Kernighan's: kill lowest set bit
    c++;
  }
  return c;
}
// O(set bits)

Where bit manipulation actually wins

ProblemBit move
"Find the unique number where every other appears twice"XOR all elements.
"Generate all subsets" (n ≤ ~25)Loop over 0..(1<<n)-1.
"Bitmask DP" (TSP, set-cover, etc.)State includes which subset is "done" — a bitmask.
"Power of 2 / power of 4 check"x & (x-1) == 0 for power of 2.
"Count set bits / hamming weight"Brian Kernighan's loop.
"Reverse bits / mirror an integer"Pairwise swap with masks.
"Compact set with n ≤ 64 elements"Use a single int as a set; ops are O(1).
Language gotchas

JavaScript: bitwise operators coerce numbers to 32-bit signed integers. (1 << 31) goes negative. Use BigInt or unsigned ops (>>>) when you need 64-bit. Python: arbitrary-precision integers — bit operations work on values up to your RAM. Java/C/Go: bounded by the type; long is 64 bits.
