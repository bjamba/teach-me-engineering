Credits & Further Reading

Where to go deeper on any module, authoritative sources for facts in this course, and the license notes for anything embedded.

Going deeper · by module

If a module isn't enough — or you want to push past what this course covers — these are the trustworthy places to go next.

Module 1 · DE Orientation

  • Fundamentals of Data Engineering — Joe Reis & Matt Housley. The canonical modern-DE textbook. Read chapters 1–3 for the mental model.
  • Data Mesh (Zhamak Dehghani). Useful conceptual context even if you don't adopt it.
  • Medallion architecture — Databricks glossary.

Module 2 · Snowflake

  • Snowflake Docs — the authoritative source. Use the search bar liberally.
  • Snowflake Quickstarts — short, free, hands-on tutorials. Great for interview-prep demos.
  • Snowflake free on-demand training (Snowflake University). Start with "Data Warehousing Workshop" and "Data Applications Workshop."
  • Warehouse considerations — internal doc, often cited in interviews.
  • select.dev blog — practical Snowflake cost optimization posts.

Module 3 · Python for DE

  • snowflake-connector-python docs.
  • Snowpark for Python docs — dataframe-style in-warehouse transforms.
  • boto3 official docs.
  • Python for Data Analysis — Wes McKinney (the pandas author). If you want to fully hydrate pandas fluency.

Module 4 · AWS for DE

  • AWS Glue docs.
  • Step Functions docs.
  • AWS Free Tier details.
  • AWS Cloud Quest: Data Analytics (free on AWS Skill Builder with a free account). Gamified walkthrough.

Module 5 · Matillion

  • Matillion docs.
  • Matillion Academy — free, self-paced courses directly from the vendor. If the interview mentions Matillion specifically, do the "Data Productivity Cloud Essentials" track.
  • Matillion YouTube channel.

Module 6 · Git + Jenkins for DE

  • schemachange on GitHub.
  • dbt docs — if you hit Jenkins pipelines for transformations, dbt is often involved even if not on the JD.
  • Your existing expertise covers this module already. Read the schemachange README, skim the Jenkins plugin for Snowflake, done.

Module 7 · Governance

  • Snowflake Access Control overview.
  • Column-level security intro.
  • Row Access Policies.
  • Snowflake Security Best Practices (whitepaper).

Module 8 · Streaming

  • Apache Kafka documentation.
  • Confluent Developer — free, high-quality Kafka tutorials.
  • Kinesis Data Streams dev guide.
  • Snowpipe Streaming overview.
  • Designing Data-Intensive Applications — Martin Kleppmann. If you want the deepest possible understanding of log-based systems, chapter 11.

Module 9 · Optimization + Utility

  • Snowflake Query Profile guide.
  • NARUC (National Association of Regulatory Utility Commissioners) — industry regulator context.
  • IEEE Smart Grid resources for reliability metrics (SAIDI/SAIFI/CAIDI).
  • DOE intro to the electric grid.
  • "How utilities use analytics" — vendor-agnostic overview.

Generalizable DE skills (beyond this JD)

If this role falls through and you want to aim at DE more broadly, these are the pieces we intentionally didn't cover because they weren't in the posting.

  • dbt — the analytics-engineering framework. Transformation-as-code, tested, versioned. If the next DE interview mentions it, the 2-hour dbt fundamentals course on the dbt Labs site gets you conversant.
  • Airflow — the most common non-Matillion orchestrator. Same job-as-DAG mental model.
  • Spark — Glue is Spark, but Spark itself (PySpark API, DataFrame ops, tuning) is worth its own study if you're going EMR/Databricks/Glue-ETL heavy.
  • Data modeling — dimensional modeling (Kimball), data vault, normalization basics. Generally valuable, only lightly touched here.
  • Delta Lake / Iceberg / Hudi — open table formats. Increasingly common, especially for Databricks/Snowflake-Iceberg interop.
  • Observability for DE — Monte Carlo, DataDog for DE, OpenLineage. Not on the JD, but this is where DevOps senses pay off.
  • GCP BigQuery / Azure Synapse — the other cloud warehouses. Concepts transfer.
