How to get these into Google Sheets

  1. Click Export TSV — a .tsv file downloads.
  2. Open Google Sheets. File → Import → Upload the TSV. Pick "Separator type: Tab."
  3. Or: open the TSV in any text editor, select all, paste directly into a Google Sheet cell — tabs become columns automatically.

TSV is the more forgiving format (commas inside notes don't break anything). Use CSV only if a tool requires it.
