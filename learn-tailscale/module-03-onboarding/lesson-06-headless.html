Headless server / Raspberry Pi

No browser, no GUI, just an SSH session. Same install as L4 (Linux), plus two tricks that make life easier on always-on machines.

1Install

SSH into the box and run the same Linux install:

curl -fsSL https://tailscale.com/install.sh | sh

This works on Raspberry Pi OS, Ubuntu Server, Debian, and most other server distros.

2Bring it up — interactive auth

If you have a browser handy on another device:

sudo tailscale up

Copy the printed URL into your laptop's browser, authorize, done. Same as L4.

3Bring it up — pre-shared auth key

For machines you'll bring up frequently (or fleets of them), use an auth keyAuth key — a pre-shared key that lets a device join your tailnet without an interactive browser login. You generate one in the admin console; it can be reusable, single-use, time-limited, ephemeral, or pre-authorized.:

  1. Go to admin console → Settings → Auth keys.
  2. Click Generate auth key. Pick:
    • Reusable: can register multiple devices. Off for one-off, on for fleets.
    • Ephemeral: device auto-removes itself when offline. Good for short-lived containers, bad for servers.
    • Pre-authorized: skips manual approval if you have device approval enabled.
    • Tags: which tags this device gets (M4 — important for ACLs).
  3. Copy the key. It looks like tskey-auth-....
  4. On the headless box: 
    sudo tailscale up --auth-key=tskey-auth-XXXXXX

No browser, no interaction. The device joins instantly.

Treat auth keys like passwords. Anyone with the key can add a device to your tailnet. Keep them out of public repos. Use single-use keys for one-off provisions.

4Make it survive reboots

Tailscale's installer registers a tailscaled service. On most distros it auto-starts on boot — but it's worth confirming:

sudo systemctl status tailscaled
sudo systemctl enable --now tailscaled  # makes sure it auto-starts

5Now SSH in over Tailscale

From any other tailnet device:

ssh you@home-server

If MagicDNS is on (you turned it on in L1), the hostname resolves directly. SSH still uses your existing keys / passwords; Tailscale just provides the network path.

Deep-path detail: if you want to skip SSH key management entirely, M4 covers Tailscale SSH (tailscale up --ssh). Tailscale handles authentication so you can ssh user@host without setting up keys. ACLs determine who can connect.

6What's next

You've added the box that will host most of the projects in this course. Verify everything works in L7, then jump to M4 to start using your tailnet.
