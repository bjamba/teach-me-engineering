macOS

App Store install, log in, done. Three minutes if your network is fast.

1Install

Two equivalent options:

  • App Store (recommended for most): search "Tailscale" or open this link. Click Get → Install.
  • Direct download: tailscale.com/download/macos. Download the .pkg, double-click, follow the installer.

Either is fine. The App Store version auto-updates; the direct version is identical otherwise.

2Log in

  1. Open Tailscale (Applications → Tailscale, or the menu bar icon).
  2. Click Log in. Your browser opens.
  3. Pick the same identity provider you used in L1.
  4. Authorize. Browser says "success." You can close it.
  5. Back in the Tailscale menu bar, you should now see "Connected" with your tailnet IP shown (e.g. 100.64.x.y).

3Verify

From the menu bar, the Tailscale icon shows a list of devices on your tailnet. Right now it's just this Mac.

Try the CLI version too — open Terminal:

tailscale status
# Lists all devices in your tailnet, with IPs and online state

tailscale ip
# Prints this Mac's tailnet IP

If tailscale is not found, run /Applications/Tailscale.app/Contents/MacOS/Tailscale instead, or install the CLI symlink: sudo ln -sfn /Applications/Tailscale.app/Contents/MacOS/Tailscale /usr/local/bin/tailscale.

4Rename if you want

Go to the Machines page. Find this Mac. Click the three-dot menu → Edit machine name. Use lowercase, no spaces (e.g. your-laptop). Save.

Now ssh your-laptop from any other tailnet device will reach this Mac (assuming SSH is enabled on the Mac, which is a separate setting).

5What's next

Add another device on a different OS to actually have something to talk to. When you're done with installs, head to L7 · Verifying it works.
