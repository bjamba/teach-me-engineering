Windows

Microsoft Store install, log in, done. Plus a note on WSL if you'll be running Linux things from Windows.

1Install the Windows app

  • Microsoft Store: search "Tailscale" or open this link. Click Get → Install.
  • Direct download: tailscale.com/download/windows. Run the installer.

2Log in

  1. Tailscale appears in your system tray (bottom-right). Click the icon.
  2. Click Log in. A browser window opens.
  3. Pick the same identity provider as in L1.
  4. Authorize. You're connected.

3Verify

Open Windows Terminal (Win + type "Terminal"). In PowerShell:

tailscale status

You should see your devices listed. If tailscale is not found, restart Windows Terminal — the PATH was updated by the installer and your existing terminal session may not have picked it up.

4WSL bonus

If you're using WSL (Windows Subsystem for Linux), Tailscale's Windows app already gives WSL access to the tailnet — no separate install needed. From your WSL Ubuntu:

tailscale status   # works because Tailscale's Windows app exposes the tailnet to WSL
ping home-server

If you want Tailscale running natively inside WSL (rare; only needed for advanced setups), follow L4 (Linux) instructions inside the WSL terminal.
