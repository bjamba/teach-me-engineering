🤖 Local AI gateway (Ollama)

Run large language models on your beefiest machine, hit them from your phone, laptop, or anywhere on your tailnet. Private, free, fast — and an excellent reason to upgrade your home GPU.

⭐ Core AI/ML Intermediate Half-day Prereqs: M3 + M4L3 (Serve)

Why this project

Cloud LLM APIs cost money and see your prompts. Local LLMs are free and private — but until now, hard to access from your phone or while traveling. With Tailscale Serve in front, your home AI rig becomes a private API that follows you everywhere.

This is also the gateway project for everything else in the AI/ML topic — RAG over your docs, scheduled summarization tasks, editor integrations all start from "I have a tailnet-reachable Ollama."

Who this helps

  • You already use ChatGPT/Claude/Gemini and want a free, private alternative for the 80% of asks that don't need a frontier model
  • You have a beefy machine at home (Apple Silicon Mac, gaming PC, server with a GPU) that's underutilized
  • You'd rather your prompts stayed on hardware you own
  • You want to plug the same private API into editor extensions (Continue, Aider, Cursor) without paying per token

What you get

  • A private API at https://ai-rig.tail-abc.ts.net that responds to OpenAI-compatible requests
  • A polished web UI (Open WebUI) reachable from any tailnet device — your personal ChatGPT alternative
  • Optional: API-key auth in front so you can share access with friends without inviting them to your tailnet
  • The ability to swap models freely without contract changes

Prerequisites

  • Tailscale running on the machine that'll host Ollama (M3)
  • Tailscale Serve concepts from M4L3
  • Docker installed if you'll use Open WebUI (most flexible install)
  • HTTPS Certificates enabled in admin → DNS

Hardware notes

  • Minimum: any computer with 16GB RAM can run smaller models (Llama 3.2 3B, Phi-3 Mini). CPU-only is fine, just slow.
  • Comfortable: Apple Silicon Mac with 32GB+ RAM, or a Linux box with an Nvidia GPU (8GB+ VRAM).
  • Excellent: a 4090 or M3 Max. You can run 70B models at usable speeds.

The instructions below work on any of these. Larger models on weaker hardware just run slower.

Steps

Install Ollama on your AI host ~5 min

curl -fsSL https://ollama.com/install.sh | sh

Download from ollama.com/download. Drag to Applications, run.

Download from ollama.com/download. Run the installer. Recommended: install in WSL Ubuntu instead, where the Linux instructions apply.

Pull a model ~5–30 min depending on speed

Start with something small to verify everything works:

ollama pull llama3.2:3b

Larger options (download once, run forever):

ollama pull llama3.1:8b           # 4.7 GB · good general model
ollama pull qwen2.5:14b           # 9 GB · stronger reasoning
ollama pull mistral-small:22b     # 13 GB · excellent
ollama pull deepseek-r1:14b       # 9 GB · reasoning

Browse ollama.com/library for more.

Test it locally ~2 min

ollama run llama3.2:3b
>>> what's the airspeed velocity of an unladen swallow?

Type /bye to exit. Confirms Ollama is working before we expose it.

Expose via Tailscale Serve ~3 min

sudo tailscale serve --bg http://localhost:11434

Output: https://your-server.tail-abc.ts.net. From any tailnet device, you can now hit Ollama's API:

curl https://your-server.tail-abc.ts.net/api/tags

You should see a JSON list of your installed models.

Try it from another device ~3 min

curl https://your-server.tail-abc.ts.net/api/generate -d '{
  "model": "llama3.2:3b",
  "prompt": "Why is the sky blue?",
  "stream": false
}'

Wait a few seconds, get a JSON response with the answer. That's a private LLM API. Your home rig is doing the inference; your laptop is just sending the prompt.

Add a web UI: Open WebUI ~10 min

Open WebUI is a ChatGPT-style frontend for Ollama. Easiest install is Docker:

docker run -d \
  -p 3000:8080 \
  -e OLLAMA_BASE_URL=http://host.docker.internal:11434 \
  -v open-webui:/app/backend/data \
  --name open-webui \
  --restart always \
  ghcr.io/open-webui/open-webui:main

Now expose Open WebUI on your tailnet:

sudo tailscale serve --bg http://localhost:3000

Visit your tailnet URL in a browser. Create an account (the first user becomes admin), pick your model, chat. From your phone, the same URL works — you've got a personal ChatGPT alternative on every device, none of your prompts leaving your home network.

Open WebUI's first-user-becomes-admin behavior is the auth: set up the admin account immediately after deploying so a tailnet visitor doesn't claim it.

Optional: API-key auth in front of the raw API ~15 min

If you want to share API access with friends without inviting them to your tailnet, put a small auth proxy in front. Caddy with a static API key check:

:11500 {
  @auth header Authorization "Bearer my-shared-secret"
  reverse_proxy @auth localhost:11434
  respond 401
}

Then Funnel localhost:11500 instead of 11434. Friends call your API with the shared secret; untrusted requests get 401.

Verify

  • curl /api/tags from a different tailnet device returns your model list
  • Open WebUI works from your phone
  • Generation responses come from your machine (you can see CPU/GPU usage spike on the host)

Common issues

  • Open WebUI can't reach Ollama — on Linux, host.docker.internal may not resolve; try --network=host or set OLLAMA_HOST=0.0.0.0:11434 on Ollama and point WebUI at the host's tailnet IP.
  • Slow responses — first request after a model is idle reloads it into memory. Try a couple of warm requests.
  • Out of memory — the model is too large for your VRAM/RAM. Pull a smaller variant or quantization.

Where this leads

  • RAG pipeline + vector DB — feed your local LLM your own docs
  • Hook Ollama into editors/CLI tools (Continue, Aider) using the tailnet URL
  • Schedule tasks against your local model — summarize emails overnight, classify newsletters
