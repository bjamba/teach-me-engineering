Gallery project

🎮 Private Minecraft / Valheim server

Friends-only multiplayer, no DDoS surface, no port forwarding. The server lives on your hardware; friends join over the tailnet.

Gallery Gaming Intermediate ~1 hr Prereqs: M3

Why this project

Hosting a Minecraft, Valheim, Factorio, or Terraria server publicly means dealing with random join attempts, DDoS noise, and griefers. Renting a hosted server costs ~$10/mo per game and depends on someone else's infrastructure. With a friends-only Tailscale tailnet, you run the server on your own hardware, friends join via tailnet hostname, and there's literally no public exposure.

Who this helps

  • You're the de-facto admin for a small group of friends who play together
  • You have a beefy desktop or home server that's idle most of the time
  • You'd rather not pay for hosted servers per-game
  • You want a whitelist that's "is this person on my tailnet" rather than "did someone share the IP again"

What you get

  • A game server running on your hardware, reachable by hostname over the tailnet
  • No port forwarding, no DDoS surface, no public IP to share
  • Whitelist via tailnet membership — invite a friend, they have access
  • Direct peer-to-peer connection when possible (low latency for nearby friends)

Prerequisites

  • A home server that's always-on with enough CPU/RAM for the game (varies wildly — Minecraft = modest, Valheim = beefier)
  • Tailscale running on your home server (M3)
  • Friends who are willing to install Tailscale

Steps

Run the game server ~15 min depending on game

Pick a Docker image:

  • Minecraft: itzg/minecraft-server
  • Valheim: lloesche/valheim-server
  • Factorio: factoriotools/factorio
  • Terraria: ryshe/terraria

Each has docs covering RAM/CPU needs, world creation, etc. Get the server running locally first; verify by joining from the same machine.

Make the host reachable on the tailnet ~3 min

Your home server should already be on the tailnet (M3L6). Tag it tag:gameserver for clean ACLs.

Game servers usually expose UDP ports (Minecraft 25565, Valheim 2456). With the host on the tailnet, those ports are reachable on the host's tailnet IP — no Serve/Funnel needed for game traffic. Game traffic isn't HTTP; Tailscale just provides the network path.

Friends join your tailnet ~5 min per friend

Invite each friend as a user (free tier supports 3 users; if you have more, paid tier or a single shared "guest" user works).

They install Tailscale, sign in, and now their machine is on your tailnet.

They connect to the server by name ~2 min

In the game's "join server" UI, friends enter your hostname:

  • Minecraft: game-server (or game-server.tail-abc.ts.net)
  • Valheim: enter the hostname in the "Join Game" → IP field
  • Most games: hostname or tailnet IP works

ACL: friends should reach only the gameserver ~3 min

{
  "groups": {
    "group:family": ["you@home"],
    "group:friends": ["alice@friend.com", "bob@friend.com"]
  },
  "tagOwners": { "tag:gameserver": ["group:family"] },
  "acls": [
    { "action": "accept", "src": ["group:family"], "dst": ["*:*"] },
    { "action": "accept", "src": ["group:friends"], "dst": ["tag:gameserver:*"] }
  ]
}

Friends can hit the game server. They can't poke at your home server, your media library, or anything else.

Verify

  • Friends successfully join the server using the hostname
  • From a friend's machine, attempting to ping other tailnet devices fails (ACL doing its job)
  • tailscale ping --until-direct <friend's device> shows direct peer-to-peer (not DERP) for low latency

Common issues

  • Friends can't connect by hostname — make sure their device has MagicDNS turned on (it's a tailnet-wide setting they inherit).
  • High latency — you're going through DERP. Run tailscale ping --until-direct to confirm; some networks won't traverse and you'll have to live with relay latency.
  • Game crashes on join — that's the game, not Tailscale. Check the game server logs.

Caveats

  • Free tier supports 3 users — for bigger friend groups, either upgrade or share a guest user (less granular ACLs)
  • Real-time games are sensitive to latency. DERP relay adds 20–50ms; turn-based games won't notice; FPS games will
  • Game-specific anti-cheat sometimes interacts oddly with VPN-style tunnels — most games are fine, a few aren't

Where this leads

  • Tech support for parents — same invite-as-user pattern, different use
  • Add server-side modding (Minecraft Spigot, Valheim mods) without exposing them publicly
  • Pair with Actions runner if you want CI for your modpack
