Featured project

🎬 Your own Jellyfin / Plex

Personal media server reachable from any of your devices, streaming over your tailnet. No subscriptions, no DDoS surface, no cloud account.

Featured Media Beginner Half-day Prereqs: M3

Why this project

Streaming services keep getting more expensive and own less of the catalog. If you have a media library you actually own — ripped DVDs, downloaded shows, family videos — Jellyfin gives you Netflix-quality UX over your own files. Tailscale fixes the historical pain of self-hosted Plex/Jellyfin: random IPs, port forwarding, "is this exposed to the internet?" anxiety. Tailnet-only by default; everywhere with you.

Who this helps

  • You have a media collection (movies, shows, audiobooks, family videos) and want one app for all your devices
  • You're tired of paying multiple streaming services for content that disappears whenever licensing shifts
  • You want to share access with family without giving the world a public URL

What you get

  • Jellyfin reachable at https://jellyfin.tail-abc.ts.net from any tailnet device
  • Native Jellyfin apps on iOS, Android, Apple TV, Android TV, browser
  • Hardware-accelerated transcoding when needed (Intel iGPU / Nvidia / Apple Silicon)
  • ACL-restricted to your family group — no public exposure

Prerequisites

  • Tailscale running on a Linux/macOS host (M3)
  • Docker + docker-compose installed
  • The Docker sidecar pattern from the Core project
  • HTTPS Certificates enabled in admin → DNS

Hardware notes

  • Minimum: any always-on machine with enough disk for your library + a few GB RAM. Direct-play to compatible clients works fine on a Pi 5.
  • Comfortable: a NUC or Mac mini with an Intel iGPU (QuickSync) or Apple Silicon. Hardware transcodes for older clients without breaking a sweat.
  • Excellent: dedicated server with Nvidia GPU. Multiple simultaneous transcodes, 4K-to-anything.

Most home servers, Pi 5s, NUCs, and Apple Silicon Minis are fine.

Steps

Run Jellyfin via the Docker sidecar pattern ~10 min

Same pattern as the Core Docker sidecar project. Save as ~/jellyfin/docker-compose.yml:

services:
  ts-jellyfin:
    image: tailscale/tailscale:latest
    hostname: jellyfin
    environment:
      - TS_AUTHKEY=${TS_AUTHKEY?required}
      - TS_EXTRA_ARGS=--advertise-tags=tag:media
      - TS_SERVE_CONFIG=/config/serve.json
      - TS_STATE_DIR=/var/lib/tailscale
    volumes:
      - ts-state:/var/lib/tailscale
      - ./serve-config.json:/config/serve.json
      - /dev/net/tun:/dev/net/tun
    cap_add: [net_admin, sys_module]
    restart: unless-stopped

  jellyfin:
    image: jellyfin/jellyfin:latest
    network_mode: service:ts-jellyfin
    environment:
      - JELLYFIN_PublishedServerUrl=https://jellyfin.tail-abc.ts.net
    volumes:
      - jellyfin-config:/config
      - jellyfin-cache:/cache
      - /path/to/media:/media:ro
    restart: unless-stopped
    devices:
      - /dev/dri:/dev/dri              # Intel/AMD iGPU for transcoding

volumes:
  ts-state:
  jellyfin-config:
  jellyfin-cache:

And the serve config serve-config.json:

{
  "TCP": { "443": { "HTTPS": true } },
  "Web": {
    "${TS_CERT_DOMAIN}:443": {
      "Handlers": { "/": { "Proxy": "http://127.0.0.1:8096" } }
    }
  }
}

Bring it up ~3 min

Generate a Tailscale auth key with tag:media. Then:

cd ~/jellyfin
export TS_AUTHKEY="tskey-auth-XXXXX"
docker compose up -d
docker compose logs -f ts-jellyfin   # wait for "Success."

Initial Jellyfin setup ~10 min

From your laptop's browser, visit https://jellyfin.tail-abc.ts.net. The Jellyfin setup wizard appears.

  • Pick your language
  • Create your admin account (use a real password)
  • Add a media library: name it "Movies" or "TV Shows", point it at /media

Jellyfin scans, finds your files, fetches metadata. Wait for the scan to finish.

Watch from any device ~3 min

  • Browser: visit your tailnet URL
  • iPhone/iPad: install "Jellyfin Mobile" from the App Store, point at the URL
  • Android / Android TV: install Jellyfin from Play Store
  • Apple TV: install Jellyfin from the App Store
  • Smart TV via Chromecast: cast from the mobile app

ACL: family access only ~3 min

Tighten access so random tagged tailnet members can't reach Jellyfin:

{
  "acls": [
    { "action": "accept", "src": ["group:family"], "dst": ["tag:media:*"] }
  ]
}

Enable hardware transcoding (optional) ~10 min

Direct play (no transcoding) works for most devices. For older clients or limited bandwidth, enable HW acceleration:

  • Intel/AMD iGPU on Linux: the /dev/dri mount enables it. Configure: Dashboard → Playback → Transcoding → "Intel QuickSync" or "AMD AMF".
  • Nvidia GPU: install Nvidia Container Toolkit, add runtime: nvidia. Worth it if you have one.
  • Apple Silicon: VideoToolbox in Jellyfin's settings.

Verify

  • Jellyfin loads at https://jellyfin.tail-abc.ts.net from any tailnet device
  • Off-tailnet visitors can't reach the URL
  • Mobile apps stream from your library while you're not at home
  • Admin console shows jellyfin as tag:media

Common issues

  • Library scan finds nothing — check the volume mount path matches what you tell Jellyfin.
  • Transcoding fails — confirm the device mount exists and Jellyfin is set to use the right encoder.
  • Mobile app says "incompatible server" — set JELLYFIN_PublishedServerUrl to your full HTTPS tailnet URL.

Variations

  • Plex: same Docker pattern, image plexinc/pms-docker, port 32400 instead of 8096.
  • Navidrome (audio-only, much lighter): image deluan/navidrome:latest, port 4533.
  • Audiobookshelf: ghcr.io/advplyr/audiobookshelf:latest, port 80.
