Exit nodes

Route your internet traffic through another tailnet device. Useful when you're on suspect wifi or want to reach things only your home network sees.

1What an exit node is

By default, only tailnet traffic goes over Tailscale. Your browser visiting google.com still goes through the local network you're on (coffee shop wifi, hotel wifi).

An exit node is a tailnet device that's offering to route everyone else's full internet traffic. When you select an exit node on your phone, all your traffic — Google, Slack, Netflix, everything — first tunnels to that exit node, then out to the internet from there.

2When this is useful

  • Public wifi safety: hotel/airport wifi can be sketchy. Exit through your home → wifi only sees encrypted Tailscale traffic, not what sites you're visiting.
  • Reach things only your home network sees: a printer, a smart bulb, an appliance UI on your home LAN. Combined with subnet routers (next lesson), exit nodes let your phone act as if it's home.
  • Apparent location: traffic appears to come from the exit node's public IP. Sometimes useful for accessing services that geofence by IP.

Not a substitute for a privacy VPN like Mullvad. An exit node makes your traffic appear to come from your home IP — fine for "skip hotel wifi snooping," not fine for "hide from your ISP" since your home IP is your ISP.

3Setting up an exit node (the host)

On the device that will be the exit node:

sudo tailscale up --advertise-exit-node

Then approve it in the admin console: Machines → click the device → Edit route settings → toggle "Use as exit node."

Linux extra step: exit nodes need IP forwarding enabled at the OS level. echo 'net.ipv4.ip_forward = 1' | sudo tee -a /etc/sysctl.d/99-tailscale.conf && sudo sysctl -p /etc/sysctl.d/99-tailscale.conf. The Tailscale installer warns you if this is missing.

4Using an exit node (the client)

  • Mac/Windows: click the Tailscale menu/tray → Exit Node → pick your home server.
  • iOS/Android: open the app → Use Exit Node → pick.
  • CLI: sudo tailscale up --exit-node=home-server

Disable: pick "None" in the menu, or sudo tailscale up --exit-node=.

5Cost and trade-offs

  • Speed: your traffic now bounces through home, so latency goes up. For most browsing it's fine; large downloads will feel slower.
  • Bandwidth: your home upstream becomes the bottleneck for whatever you're doing on the move.
  • Trust: the exit node sees the destination of all your traffic (not the contents — those are still HTTPS-encrypted to the destination — but where you went). Use a device you trust.
