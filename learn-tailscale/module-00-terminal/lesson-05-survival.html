Survival tips

Five small habits that will keep you confident and safe through the rest of this course.

1Don't paste commands you can't read

It is genuinely common for blogs to suggest curl example.com/install.sh | sudo bash. This downloads a script and immediately runs it as administrator — you have no idea what's in it. Don't do this from random sources.

For Tailscale itself, the install scripts come from tailscale.com, signed by the company, and are widely audited. That's safe. But:

Rule: if a tutorial tells you to sudo a script you didn't read, and the source isn't a well-known project's official site, pause. Ask why. Read the script first (curl example.com/install.sh | less).

2The five-minute time machine: ↑ arrow

Press the up arrow at an empty prompt. The terminal shows the previous command you ran. Press it again — the one before that. This is your history.

To search history, type Ctrl + R and start typing — the terminal shows the most recent command matching what you've typed. Press Enter to run it, or → to edit it first.

3Tab completion is your friend

Hitting Tab mid-command auto-completes. Filenames, command names, sometimes even flag names (depending on shell). Use it constantly — it's faster and catches typos.

Hit Tab twice to see all possibilities if there are multiple matches.

4If something looks weird, just close the window

The terminal is a window. Closing it doesn't break anything on your computer. If you accidentally end up in some mode you don't understand (an editor you didn't mean to open, a command waiting for input forever, a stuck SSH session), close the window and open a new terminal.

You haven't damaged anything. The terminal is genuinely just a window.

5Three commands worth memorizing

which tailscale     # where is this command installed?
tailscale status    # is Tailscale running, and what does it see?
ping example.com    # is the network actually working?

These three answer 80% of "is it working?" questions. Run them whenever you're confused.

You're done. You now have everything you need to follow the rest of the course at the terminal. The actual networking is what's coming next — and that's a different skill.
