What is the terminal

A second window into your computer. Less pretty than the apps you know, but more direct.

1Two ways to use a computer

Almost everything you do on your computer goes through a graphical interface — windows, icons, buttons. This is one way to talk to your machine.

The other way is the terminal: a text window where you type a command and the computer types back. It looks like nothing, on purpose — there are no menus, no icons, just a blinking cursor waiting for instructions.

Mental model: the GUI is "I'd like a coffee, oat milk, no sugar, in that mug." The terminal is "make coffee, oat, dry." Same outcome. The terminal is shorter once you know the words.

2Why we use it for Tailscale things

Tailscale itself has a perfectly good app — you'll install it from a clickable installer in M3. The terminal shows up later, mostly when we want to:

  • Install Tailscale on a Linux box or Raspberry Pi that has no GUI
  • Run tailscale serve or tailscale up --advertise-routes=... to enable a feature
  • Edit a configuration file (a Docker compose file, an Ollama config)
  • Check whether something is working: "is Ollama actually listening on port 11434?"

These all take one or two commands. None of them require you to be a wizard.

3How to open one

macOS: press ⌘ Space, type Terminal, hit Enter. (Or use iTerm2 / Warp / Ghostty if you've installed one — same idea.)

Windows: press the Win key, type Terminal, hit Enter. This opens Windows TerminalWindows Terminal — the modern terminal app on Windows. It can run multiple shells (PowerShell, Command Prompt, WSL)., which by default runs PowerShell. We'll mostly use WSLWSL (Windows Subsystem for Linux) — runs a real Linux environment inside Windows. The Tailscale instructions in this course assume WSL on Windows for any Linux command. — install Ubuntu from the Microsoft Store and you'll have a Linux terminal one click away.

Linux: you already know. Ctrl + Alt + T on most distros, or click "Terminal" in your launcher.

iPad/iPhone/Android: none of the projects in this course require a phone terminal. If you ever want one, Termius is the cleanest option, but skip it for now.

4Anatomy of a prompt

You'll see something like:

you@laptop ~ $

That's the prompt. It's the terminal saying "I'm ready, what do you want?" The exact text depends on your shell config, but roughly:

  • you — your username
  • laptop — your computer's hostname
  • ~ — your current directory (the tilde means your home folder)
  • $ — "I'm ready"

When this course shows a command, we'll just write it as tailscale up — without the prompt. You type the command, hit Enter, and the terminal does the thing.

Don't type the $ or # if you ever see one in front of a command online. It's just convention to indicate "this is a command."

5Try it: your first command

Open a terminal and type: 

echo hello

Press Enter. The terminal will reply with hello. Congratulations — you've now used a terminal. Try a few more: 

date
whoami
uname -a

These tell you the time, your username, and what operating system you're on. None of them change anything; they just print stuff. That's most of what you'll do in this course.

The aha: the terminal is just a text window. You type, it answers. There is no scary mode you might have accidentally entered. If something looks weird, you can always just close the window and start over.
