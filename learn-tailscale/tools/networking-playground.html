🔬 Networking playground

Tiny interactive labs for the four foundational concepts. Try inputs, see outcomes, build intuition.

IP classifier

Type any IPv4 address. Find out if it's private, public, CGNAT (Tailscale), loopback, or special.

Enter an IP and click Classify.

Port lookup

Type a port number. Find out what service typically runs there.

Enter a port and click Look up.

CIDR explorer

What does 192.168.1.0/24 actually mean? Type a CIDR range to see its first IP, last IP, and how many addresses it covers.

Enter a CIDR range and click Explore.

DNS resolution flow

Type a hostname. Watch a simulated DNS lookup chain — how the resolver climbs the hierarchy.

Enter a hostname and click Resolve.
