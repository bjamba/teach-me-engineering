Layout Gallery

Six common layouts. Each one gives you the HTML and asks you to write the CSS. Edit the CSS on the left and watch the preview on the right update live. "Show solution" when you're stuck.

How to use this

Try writing the CSS yourself first. Only reveal the solution if you're truly stuck or want to check your approach. The goal is muscle memory — you'll build these patterns a thousand times in your career.

Your CSS runs inside each sandbox's iframe, scoped to that exercise. You can't break anything.
