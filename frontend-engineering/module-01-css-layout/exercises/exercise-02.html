Dashboard Shell — the first capstone piece

Build the chrome of your analytics dashboard: sidebar with navigation, top bar with search and user menu, main content area, and a collapsible right panel. This file is literally what you'll open in Module 2 to start wiring up real React.

🎯
Capstone piece. The output of this exercise is a real deliverable — the HTML/CSS foundation of your dashboard. In Module 2 we'll port it to React + TypeScript. In Module 6 we'll theme it. By Module 7 it holds charts.

The brief

You're building a standard SaaS dashboard shell. Four regions:

  1. Sidebar (left, ~220px): logo at top, nav items, user avatar at the bottom
  2. Top bar (across the top of main+panel, ~60px): search input + breadcrumb + icons on the right
  3. Main (center, flexes to fill): content area — a KPI row across the top, then placeholder for a chart
  4. Right panel (right, ~280px): activity feed or filters

It should be responsive: below ~800px, collapse the right panel and let the sidebar become an overlay later (the collapse is enough for this exercise — overlay behavior needs JS, which we'll do in Module 2).

Visual reference

If you need visual inspiration: Linear, Vercel dashboard, Planetscale, Supabase. Look at them, don't copy pixel-for-pixel. Build for structure first, polish second.

Tools for this exercise

Layout

One big grid-template-areas on the outer container. Named regions: sidebar, topbar, main, panel.

Inside each region

Flex. The sidebar is flex-direction: column with margin-top: auto on the user menu to push it down.

Colors

Use CSS custom properties for bg, surface, text, accent, border. Dark mode default — put your vars on :root.

KPI row inside main

grid-template-columns: repeat(auto-fit, minmax(160px, 1fr)) — four cards that collapse to 2 on narrow.

Build it

The HTML is already written — you can see it in the HTML tab. Your job is the CSS. Solution is revealed with the button but don't look until you've spent real time on it.

Preview

Checks before you call it done

  • Does the sidebar have logo at top and user menu at the bottom (not at the middle)? margin-top: auto on the user element.
  • Does the search input fill available horizontal space in the top bar? flex: 1 on .search.
  • Do the KPIs line up in a single row on desktop and reflow on narrow screens?
  • Is the whole thing sized to 100vh with no scrollbars at desktop width?
  • Resize your window to ~700px — does the right panel gracefully disappear or stack?

When you're happy, copy your CSS and paste it into ../../capstone/dashboard-shell.css — or wait for Module 2 and we'll start the real React project.
