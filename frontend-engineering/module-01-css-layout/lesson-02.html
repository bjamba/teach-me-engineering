Flexbox Deeply

Flexbox is a one-dimensional layout system. Learn the two-axis mental model once, and every property becomes obvious.

⏱ 25 min 🎯 One mental model 🛠 Full playground

The only mental model you need

Flexbox has one big idea: items are laid out along a main axis, and the perpendicular direction is the cross axis. Every flexbox property either aligns things along the main axis or along the cross axis. That's it.

By default flex-direction: row means the main axis goes left-to-right. If you flip to flex-direction: column, the main axis becomes vertical — and all the alignment properties you thought you knew swap meaning. This is where people get confused, but once you internalize "main and cross", you never are again.

The cheat sheet

justify-content → alignment along the main axis (the one items flow along).

align-items → alignment along the cross axis (perpendicular, for a single row/column).

align-content → alignment of multiple rows/columns along the cross axis (only matters when items wrap).

Memorize those three — they cover 95% of flex alignment.

Try these moves

  1. Set flex-direction: column and watch justify-content now control vertical placement. The property name didn't change — the axis it acts on did.
  2. Center something in both axes: justify-content: center; align-items: center;. The famous "impossible in old CSS" problem.
  3. Set flex-wrap: wrap and shrink the window. Watch items flow to a new line.
  4. Change gap. Appreciate that this was genuinely hard to do before 2021.

flex: 1 — the most important line

Inside a flex container, a child's size is controlled by three properties you rarely set individually:

  • flex-grow — how much this item should grow to fill extra space (0 = don't grow)
  • flex-shrink — how much to shrink when space is tight (1 = shrink normally)
  • flex-basis — the starting size before growing/shrinking (auto = use width or content)

In practice, you almost always use the shorthand flex:

/* the three most useful values */
flex: 1;        /* grow equally with siblings, shrink equally */
flex: 0 0 auto; /* don't grow, don't shrink — stick to your natural size */
flex: 0 0 240px;/* fixed 240px, never grow or shrink */

A sidebar next to a main content area is flex: 0 0 240px for the sidebar, flex: 1 for the main. That's the entire "sidebar + content" pattern in two lines.

When NOT to use flexbox

Flexbox is one-dimensional. It's optimal for laying things out along a single row or column — navigation bars, toolbars, button rows, lists. It can wrap onto multiple rows, but it can't align items across rows into a consistent grid — each row is independent.

The moment you need rows AND columns that align (a card grid, a dashboard with named areas, a form with aligned labels/inputs), use CSS Grid. That's Lesson 3.

Rule of thumb

Flex for components (a toolbar, a button group, a header).

Grid for layouts (the page, a card grid, a dashboard).

You'll nest them freely — a grid with flex components inside its cells is extremely normal.

The small things that matter

  • gap > margin. Always. Gap is easier to tune, doesn't leak, doesn't collapse.
  • If an item needs to be pushed to the opposite end, margin-left: auto is the trick. In a nav bar: logo, three links, margin-left: auto on the sign-in button. Done.
  • Flex items have min-width: auto by default, which can prevent shrinking below the content's natural width (surprising overflow). If you see a flex item refusing to shrink, try min-width: 0.
  • align-self lets one child override align-items for itself.

Self-check

You have a page header with a logo on the left and three nav links on the right. Write it.

header {
  display: flex;
  align-items: center;
  gap: 1rem;
}
header nav { margin-left: auto; }
header nav ul {
  display: flex;
  gap: 1.5rem;
  list-style: none;
  padding: 0;
}

Five CSS rules. No floats, no positioning, no media queries. That's modern layout.
