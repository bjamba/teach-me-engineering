Planned lessons

preview

The data-viz landscape, honestly

Recharts (easy), Visx (mid), D3 (full control), Observable Plot (concise), Nivo (pretty). Which to pick and why — no hedging.

D3 for React developers — the scales, not the DOM

You don't need D3 for the DOM part — React does that. You need D3 for scaleLinear, scaleBand, scaleTime, axis generators, and geometric helpers. That's the core.

The standard charts, done well

Line, bar, area, scatter — with Recharts. When to stack, when not to. Tooltip design. Legend design. Null/missing data.

Non-standard charts with Visx and custom SVG

Sankey, radial bar, calendar heatmap, bump chart, stream graph, beeswarm. When each is the right tool (and when it's just noise).

Interaction patterns that make charts feel alive

Brush-to-zoom, hover crosshair, synced tooltips across charts, drill-down, click-to-filter. The small touches that matter.

Performance — when to stop using SVG

Canvas vs SVG vs WebGL. How to render 100k points without lagging. regl and deck.gl. When to give up and render a bitmap server-side.

Accessibility for charts

SVG role="img", aria-label, data tables as fallback, patterns and textures (not just color), keyboard-navigable chart elements.

Planned exercises

Build 8 chart types with the same dataset

Line, bar, area, scatter, sankey, calendar heatmap, radial bar, bump. Compare which communicates what.

Capstone chart library

A <Chart> primitive that handles margins, axes, legend, tooltip, and lets specific chart types plug in. The primitive that powers every chart in your dashboard.

The "one non-standard chart" challenge

Pick the most unusual chart that genuinely helps your dataset. Build it. Defend it.
