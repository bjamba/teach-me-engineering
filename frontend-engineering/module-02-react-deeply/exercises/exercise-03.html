Dataset Store — the capstone's state layer

Scaffold the capstone as a real React + TypeScript + Vite project. Wire up TanStack Query for dataset data and a Zustand store for UI state. This is the foundation everything else builds on.

🎯
Capstone piece. After this exercise you will have a working React app with the data layer wired up — load datasets, select one, manage UI state. In Module 3 we add components. Module 7 adds charts. Module 8 adds mobile.

What you're building

A Vite + React + TypeScript project that:

  • Renders the dashboard shell from Module 1 Exercise 2 (as React components)
  • Loads a list of "datasets" from a mock API (TanStack Query)
  • Has a Zustand store for UI state (selected dataset, sidebar open, etc.)
  • Is typed end-to-end

Prerequisites

  • Node.js 20+ (node --version in your terminal)
  • npm or pnpm (pnpm preferred — same lock file format, faster, disk-efficient)

Step 3 — the Zustand UI store

// src/stores/uiStore.ts
import { create } from "zustand";

type UiState = {
  sidebarOpen: boolean;
  selectedDatasetId: string | null;
  theme: "dark" | "light";

  toggleSidebar: () => void;
  selectDataset: (id: string | null) => void;
  toggleTheme: () => void;
};

export const useUiStore = create<UiState>((set) => ({
  sidebarOpen: true,
  selectedDatasetId: null,
  theme: "dark",

  toggleSidebar: () => set((s) => ({ sidebarOpen: !s.sidebarOpen })),
  selectDataset: (id) => set({ selectedDatasetId: id }),
  toggleTheme: () => set((s) => ({ theme: s.theme === "dark" ? "light" : "dark" })),
}));

Use in components — and always select the slice:

// Selects only sidebarOpen — component re-renders only when sidebarOpen changes,
// not when other store fields change.
const sidebarOpen = useUiStore((s) => s.sidebarOpen);
const toggleSidebar = useUiStore((s) => s.toggleSidebar);

Anti-pattern to avoid

Don't do const store = useUiStore() to grab everything. That subscribes the component to every change in the store, defeating the point.

Step 4 — TanStack Query setup

// src/app/providers.tsx
import { QueryClient, QueryClientProvider } from "@tanstack/react-query";
import { ReactQueryDevtools } from "@tanstack/react-query-devtools";
import { PropsWithChildren } from "react";

const queryClient = new QueryClient({
  defaultOptions: {
    queries: {
      staleTime: 60_000,
      retry: 1,
      refetchOnWindowFocus: true,
    },
  },
});

export function Providers({ children }: PropsWithChildren) {
  return (
    <QueryClientProvider client={queryClient}>
      {children}
      <ReactQueryDevtools initialIsOpen={false} />
    </QueryClientProvider>
  );
}

Wrap the app in main.tsx:

// src/main.tsx
import React from "react";
import ReactDOM from "react-dom/client";
import { Providers } from "./app/providers";
import { App } from "./app/App";
import "./index.css";

ReactDOM.createRoot(document.getElementById("root")!).render(
  <React.StrictMode>
    <Providers>
      <App />
    </Providers>
  </React.StrictMode>
);

// src/features/datasets/types.ts
export type Dataset = {
  id: string;
  name: string;
  rowCount: number;
  updatedAt: string;
};
// src/features/datasets/api.ts
import datasetsJson from "@/mocks/datasets.json";
import type { Dataset } from "./types";

// Simulate a network request — replace with real fetch when you have an API.
function delay<T>(value: T, ms = 400): Promise<T> {
  return new Promise((resolve) => setTimeout(() => resolve(value), ms));
}

export async function listDatasets(): Promise<Dataset[]> {
  return delay(datasetsJson as Dataset[]);
}

export async function getDataset(id: string): Promise<Dataset | undefined> {
  return delay((datasetsJson as Dataset[]).find((d) => d.id === id));
}
// src/features/datasets/queries.ts
import { useQuery } from "@tanstack/react-query";
import { listDatasets, getDataset } from "./api";

export const datasetsKey = () => ["datasets"] as const;
export const datasetKey  = (id: string) => ["dataset", id] as const;

export function useDatasets() {
  return useQuery({ queryKey: datasetsKey(), queryFn: listDatasets });
}

export function useDataset(id: string | null) {
  return useQuery({
    queryKey: id ? datasetKey(id) : ["dataset", "none"],
    queryFn: () => (id ? getDataset(id) : Promise.resolve(undefined)),
    enabled: !!id,
  });
}

Why centralize query keys as functions?

Every place that touches a queryKey imports the same function. If you rename or restructure, one change. For mutations that invalidate, you use the same function. Avoids "I thought the key was ['datasets'] but that one place used ['dataset']" bugs.

Step 6 — connect it all

// src/features/datasets/DatasetList.tsx
import { useDatasets } from "./queries";
import { useUiStore } from "@/stores/uiStore";

export function DatasetList() {
  const { data, isPending, error } = useDatasets();
  const selectDataset = useUiStore((s) => s.selectDataset);
  const selectedId = useUiStore((s) => s.selectedDatasetId);

  if (isPending) return <p>Loading…</p>;
  if (error) return <p>Couldn't load datasets.</p>;

  return (
    <div className="dataset-list">
      {data.map((d) => (
        <button
          key={d.id}
          className={"dataset-row" + (selectedId === d.id ? " active" : "")}
          onClick={() => selectDataset(d.id)}
        >
          <strong>{d.name}</strong>
          <span>{d.rowCount.toLocaleString()} rows · updated {d.updatedAt}</span>
        </button>
      ))}
    </div>
  );
}
