Build an Accessible Dialog from Scratch

You just read about what Radix does. Now build your own Dialog that handles the five most important concerns correctly: focus trap, Escape to close, backdrop click, scroll lock, and ARIA. In production you'd use Radix — here, the point is to understand the machinery.

The brief

Build a <Dialog> component with the API below. Your implementation must pass every checklist item in the "What it must do" section. A working reference solution is at the bottom — read it only after you've taken your own shot.

The API

<Dialog open={open} onOpenChange={setOpen} title="..." description="...">
  {/* children = body */}
  <button onClick={() => setOpen(false)}>Cancel</button>
  <button onClick={confirm}>Confirm</button>
</Dialog>

What it must do

1

Portal to document.body

Use ReactDOM.createPortal. Otherwise it inherits overflow: hidden or transform from an ancestor and clips.

2

ARIA wiring

Container: role="dialog", aria-modal="true", aria-labelledby pointing at the title's id, aria-describedby pointing at the description's id.

3

Focus trap

Tab inside the dialog cycles within. Shift+Tab wraps. Focus on the first focusable element when opening. When closed, return focus to the element that opened it.

4

Escape closes

Attach a keydown listener on mount; detach on unmount. Call onOpenChange(false).

5

Backdrop click closes

Click on the backdrop (not on the panel) closes. Check e.target === e.currentTarget.

6

Scroll lock

Set body.style.overflow = "hidden" when open; restore on close. Otherwise the page scrolls behind the dialog.

Try it here — a working reference

Open the dialog and try every item on the checklist. Tab inside it. Hit Escape. Click the backdrop. Notice that focus returns to the "Open" button on close.

The reference solution — read after attempting

import { useEffect, useRef, useId } from "react";
import { createPortal } from "react-dom";

function Dialog({ open, onOpenChange, title, description, children }) {
  const titleId = useId();
  const descId = useId();
  const panelRef = useRef(null);
  const triggerRef = useRef(null);

  // 1. remember the element that had focus when we opened
  useEffect(() => {
    if (open) {
      triggerRef.current = document.activeElement;
    }
  }, [open]);

  // 2. focus the first focusable thing in the panel on open;
  //    restore to the trigger on close
  useEffect(() => {
    if (!open) {
      triggerRef.current?.focus?.();
      return;
    }
    const panel = panelRef.current;
    if (!panel) return;
    const focusables = panel.querySelectorAll(
      'a, button, input, textarea, select, [tabindex]:not([tabindex="-1"])'
    );
    focusables[0]?.focus();
  }, [open]);

  // 3. Escape closes; Tab cycles
  useEffect(() => {
    if (!open) return;
    const onKey = (e) => {
      if (e.key === "Escape") {
        onOpenChange(false);
        return;
      }
      if (e.key !== "Tab") return;
      const panel = panelRef.current;
      if (!panel) return;
      const focusables = [...panel.querySelectorAll(
        'a, button, input, textarea, select, [tabindex]:not([tabindex="-1"])'
      )].filter(el => !el.disabled);
      if (focusables.length === 0) return;
      const first = focusables[0];
      const last = focusables[focusables.length - 1];
      if (e.shiftKey && document.activeElement === first) {
        e.preventDefault();
        last.focus();
      } else if (!e.shiftKey && document.activeElement === last) {
        e.preventDefault();
        first.focus();
      }
    };
    window.addEventListener("keydown", onKey);
    return () => window.removeEventListener("keydown", onKey);
  }, [open, onOpenChange]);

  // 4. scroll lock
  useEffect(() => {
    if (!open) return;
    const prev = document.body.style.overflow;
    document.body.style.overflow = "hidden";
    return () => { document.body.style.overflow = prev; };
  }, [open]);

  if (!open) return null;

  return createPortal(
    <div
      className="dlg-backdrop"
      onClick={(e) => { if (e.target === e.currentTarget) onOpenChange(false); }}
    >
      <div
        ref={panelRef}
        role="dialog"
        aria-modal="true"
        aria-labelledby={titleId}
        aria-describedby={descId}
        className="dlg-panel"
      >
        <h3 id={titleId}>{title}</h3>
        <p id={descId}>{description}</p>
        {children}
      </div>
    </div>,
    document.body
  );
}

Things to notice in the solution

  • useId for stable SSR-safe IDs that link aria-labelledby and aria-describedby.
  • Each concern is a separate effect. Keep effects narrow — one responsibility each.
  • The Tab handler only intervenes at the edges (first → wrap, last → wrap). It doesn't fight the browser's default Tab cursor.
  • We intentionally don't filter by [inert], disabled visibility, or elements with display: none. For a real implementation, use the tabbable library, which handles all the edge cases.
  • For production, also handle: nested dialogs (stack of traps), the inert attribute on siblings, animated exit (delay unmount), and the rare case where the trigger was removed from the DOM while the dialog was open.

Self-check — open the live demo above and verify

  • Open the dialog. Focus should land on the first button inside.
  • Press Tab a few times. Focus should cycle between the two buttons, never escaping to the page behind.
  • Press Shift+Tab from the first button. It should wrap to the last.
  • Press Escape. Dialog closes. Focus returns to the "Open dialog" button on the page.
  • Open again. Click the backdrop. Dialog closes.
  • Open again. Click inside the panel. Nothing happens (we don't close on internal clicks).
  • Try scrolling the page while the dialog is open. It shouldn't scroll.
