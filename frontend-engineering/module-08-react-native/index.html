Module 8

React Native for Mobile

React Native is not "React, for mobile" — it's a different runtime, different primitives, and different constraints. Once you understand the mental-model shift, everything you've learned about React still applies. We'll build a companion mobile app for your dashboard.

Planned lessons

preview

The mental-model shift — from DOM to native views

No <div>. No CSS stylesheets. <View>, <Text>, <ScrollView>, Flexbox only (and it's slightly different). What translates, what doesn't.

Expo — the right way to start

Why bare React Native is a trap for solo devs. expo, eas build, OTA updates, Expo Router. You can have a working app on your phone in 20 minutes.

Navigation — Expo Router / React Navigation

File-based routing (like Next.js). Stack, tabs, drawers. Deep linking. Type-safe routes.

Styling mobile — StyleSheet, NativeWind, and themes

StyleSheet.create vs inline vs NativeWind (Tailwind for RN). Sharing design tokens between web and native.

Gestures and animation — Reanimated 3 and Gesture Handler

Why RN animations run on the UI thread and why that matters. The shared-value model. A swipeable card from scratch.

Platform patterns — iOS vs Android

Navigation gestures, keyboard avoidance, safe areas, haptics, platform-specific components. When to branch, when not to.

Data — sharing code between web and native

TanStack Query and Zustand work identically on both. Reuse your data layer from the capstone. A shared packages/core structure.

Planned exercises

Set up Expo and ship "Hello World" to your phone

Install Expo Go, create an app, scan the QR code, see it on your device. The fastest confidence-boost in mobile dev.

Port one chart from the web dashboard to the mobile app

Pick a chart. Use Victory Native or react-native-svg. Share the data-fetch layer with the web app.

Capstone mobile companion

Dataset list view, single-chart drill-down, pull-to-refresh, offline cache. The mobile face of your dashboard.
